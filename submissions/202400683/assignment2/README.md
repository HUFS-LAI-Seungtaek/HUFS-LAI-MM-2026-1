# Assignment 2: Schema-Guided Image Classification on WikiArt

OpenRouter API와 agentic coding 도구(Antigravity)를 사용하여 `huggan/wikiart` 이미지 20개를 분류한 프로젝트입니다.

## 사용 모델

- `nvidia/nemotron-3-nano-omni-30b-a3b-reasoning:free`

## 실행 방법

필요한 패키지를 설치합니다:
```bash
pip install -r requirements.txt
```

API 토큰 설정:
프로젝트 루트 디렉토리의 `.env` 파일에 다음과 같이 API 토큰이 설정되어 있어야 합니다.
```text
OPENROUTER_TOKEN=your_openrouter_api_token
```

분류 스크립트 실행:
```bash
python classify_wikiart.py --limit 20
```

- `--limit`: 분류할 이미지 개수 (기본값: 20)
- `--request-timeout`: 요청당 제한 시간 (기본값: 20.0초)
- `--workers`: 병렬 프로세스 수 (기본값: 2)

1. **지시문 1 (목표 전달 및 언급되지 않은 조건 추가)**:
