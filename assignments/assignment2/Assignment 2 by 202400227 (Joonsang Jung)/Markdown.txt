# Assignment 2: Schema-Guided Image Classification on WikiArt

WikiArt 데이터셋의 이미지를 분석하여 인물, 동물, 꽃의 유무를 분류하고 그 근거를 추출하는 프로젝트입니다.

## 🛠️ 개발 환경 및 모델
- **사용한 모델:** `google/gemini-2.0-flash-001` (OpenRouter API)
- **에이전틱 코딩 도구:** Claude Code
- **데이터셋:** `huggan/wikiart` (20개 샘플 사용)

## 🚀 실행 방법
1. `.env` 파일에 `OPENROUTER_API_KEY`를 설정합니다.
2. 필요한 라이브러리를 설치합니다: `pip install -r requirements.txt`
3. 스크립트를 실행합니다: `python classify_wikiart.py`
4. 생성된 `results.html`을 확인합니다.

## 🤖 Agentic Coding 주요 지시문
1. "OpenRouter API와 JSON Schema를 사용하여 WikiArt 이미지를 분류하는 스크립트를 작성해줘. 응답 결과는 반드시 `has_human`, `has_animal`, `has_flower`, `reasoning` 키를 포함해야 해."
2. "분류된 결과와 저장된 이미지를 매칭하여, 한눈에 비교할 수 있는 깔끔한 HTML 리포트 파일을 자동으로 생성하는 함수를 추가해줘."

## 🧐 결과 분석

### 흥미로웠던 사례 (Interesting Cases)
1. **추상화 속 형태 인지:** 형체가 불분명한 추상화임에도 불구하고, 중앙의 붓터치 곡선을 보고 "foreground의 곡선이 인물의 팔과 닮았다"며 `has_human: yes`로 판단한 사례가 인상적이었습니다.
2. **동상의 인물 분류:** 실제 사람이 아닌 조각상 이미지를 인식했을 때, 재질은 돌이지만 형태가 인물임을 정확히 파악하여 분류했습니다.
3. **배경의 작은 요소:** 전경이 아닌 먼 배경(background)에 아주 작게 그려진 꽃들을 놓치지 않고 찾아낸 점이 놀라웠습니다.

### 한계점 및 오판 사례 (Mistakes/Limitations)
1. **의복의 무늬:** 인물이 입고 있는 옷에 그려진 화려한 꽃무늬를 보고 실제 꽃(`has_flower: yes`)이 존재한다고 잘못 판단한 사례가 있었습니다.
2. **반려동물 오인:** 인물의 머리카락이나 털 코트를 배경의 질감과 혼동하여 동물로 오인할 가능성이 보였습니다.
